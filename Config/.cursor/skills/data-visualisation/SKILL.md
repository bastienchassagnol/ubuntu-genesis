# Data visualisation: references

The `data-visualisation` rule holds the workflow order, export settings and
checklist. Read only the file you need.

| Read when | File |
|---|---|
| Before any plot: gallery search (`scripts/search_viz.py`) | `references/dataviz-inspiration.md` |
| Choosing a chart for the data | `references/chart-chooser.md` |
| Writing ggplot2 code; house theme `theme_slide()`, colour roles | `references/ggplot2-production.md` |
| Checking a chart for pitfalls (`# avoid` / `# prefer`) | `references/caveats.md` |
| Redesigning a line chart | `references/line-chart-makeover.md` |
| Interactive ladder, galleries | `references/libraries.md` |
| Palettes and colour rules | `references/colour-palettes.md` |
| Fonts, `slide_family()`, ragg/svglite, SVG to PDF | `references/fonts.md` |
| Scatter with threshold and labels | `references/annotated-scatter.md` |
| PCA and latent projections | `references/latent-projection.md` |
| Treemap | `references/treemap.md` |
| Ternary plot | `references/ternary.md` |
| Clinical waterfall | `references/waterfall-clinical.md` |
| Differential expression, maths notation (`latex2exp`) | `references/differential-expression.md` |
| Enrichment (ORA, GSEA) | `references/enrichment-plots.md` |

Interactive slides (OJS, D3, React in reveal.js): **quarto-revealjs** skill.
Before publishing: **roast-my-chart**.
